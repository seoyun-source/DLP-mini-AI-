# AI 기반 개인정보(PII) 탐지 & 마스킹 데모

정규식(구조화된 패턴) + Gemini API(문맥적 개인정보)를 결합한 하이브리드 PII 탐지 도구입니다.
DLP(Data Loss Prevention) 솔루션의 기본 구조를 미니 버전으로 구현했습니다.

## 실행 방법

### 1. Gemini API 키 발급 (무료, 카드 불필요)
1. https://aistudio.google.com 접속 후 구글 계정으로 로그인
2. "Get API key" 클릭 → 키 생성 및 복사

### 2. 로컬 실행

```bash
# 가상환경 생성 (선택, 권장)
python -m venv venv
source venv/bin/activate   # Windows는 venv\Scripts\activate

# 패키지 설치
pip install -r requirements.txt

# 앱 실행
streamlit run app.py
```

실행하면 브라우저에서 `http://localhost:8501` 이 자동으로 열립니다.
사이드바에 발급받은 API 키를 붙여넣고 "탐지 시작"을 누르면 됩니다.

## 구조 설명 (면접용 요약)

1. **1차 필터 (정규식)**: 전화번호, 이메일, 주민번호처럼 구조가 명확한 패턴은
   정규식으로 빠르고 정확하게 탐지. 비용도 들지 않고 오탐 가능성도 낮음.
2. **2차 필터 (Gemini API)**: "김민수 대리" 같은 이름+직책 조합이나 은근한 위치 언급처럼
   패턴만으로는 잡기 어려운 문맥적 개인정보를 LLM 프롬프트로 탐지.
   구조화된 출력(JSON)을 받도록 프롬프트를 설계해 파싱 안정성을 확보.
3. **마스킹 & 리포트**: 탐지된 항목을 `[유형]`으로 치환하고, 유형별 건수를
   집계해 리스크 리포트로 제공.

## 한계와 개선 방향
- 오탐/미탐(false positive/negative) 처리 로직 없음 → 실사용 시 사람 검토(HITL) 필요
- 무료 티어 API는 요청 속도 제한이 있어 대용량 처리에는 부적합
- 민감한 실데이터를 다룰 경우 온프레미스/자체 모델 검토 필요 (무료 API는 데이터가
  서비스 개선에 활용될 수 있음)
